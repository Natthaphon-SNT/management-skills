# กำหนดส่งรายงานและการแจ้งเตือน

- กำหนดส่ง = วันสิ้นสุดการอบรม + 3 วันปฏิทิน รวมเสาร์–อาทิตย์และวันหยุด ใช้วันที่ธุรกิจ Asia/Bangkok เช่น สิ้นสุด 22 ตุลาคม กำหนดส่ง 25 ตุลาคม ภายในวันนั้น
- ช่องกำหนดส่งคำนวณอัตโนมัติ เซิร์ฟเวอร์คำนวณซ้ำทุกครั้งที่บันทึก จึงแก้กำหนดผ่าน API ไม่ได้ รายการเดิมปรับตามกติกาใหม่ด้วย migration
- วันที่รายงานเลือกได้ตั้งแต่วันสิ้นสุดการอบรมถึงวันนี้ หากยังอบรมไม่สิ้นสุด ระบบแจ้งเหตุผลและยังส่งผลไม่ได้ หากส่งเกินกำหนดยังบันทึกได้ เพื่อปิดรายการค้าง
- แจ้ง ADMIN ที่ใช้งานและอนุมัติแล้วก่อนกำหนด 1 วัน ในวันกำหนด และหลังเกินกำหนด จนมีผลการนำไปใช้ ไม่เตือนรายการยกเลิก การรันซ้ำในวันเดียวกันไม่สร้างข้อความซ้ำสำหรับผู้รับและช่องทางเดิม
- แอดมินเห็นคำเตือนเมื่อเปิดระบบ และดูรายละเอียดที่ **การแจ้งเตือน** อีเมลที่ยังไม่ส่งจะยกเลิกเมื่อกรอกผลแล้ว ยกเลิกกิจกรรม หรือตั้งกำหนดใหม่

## อีเมลอัตโนมัติ

ตั้งอีเมลบัญชี ADMIN ในหน้าทะเบียนและการตั้งค่า แล้วตั้ง `SMTP_URL`, `MAIL_FROM` และ `CRON_SECRET` ใน Vercel เปิด Cron ตาม `vercel.json` ซึ่งเรียก `/api/cron` ทุกวัน โดยใช้ Bearer token จาก `CRON_SECRET` ห้ามเปิด endpoint นี้ให้เรียกโดยไม่มี token

หากไม่มี SMTP จะมีการแจ้งในระบบ แต่ไม่สามารถส่งอีเมลได้ หน้าแจ้งเตือนแสดงสถานะส่งไม่สำเร็จตามจริง รอบตรวจรายวันไม่ใช่การรับประกันแจ้ง ณ นาทีใดนาทีหนึ่ง

## ค้นหาและส่งออก

หน้าตัวกรองมีปีงบประมาณ ไตรมาส ฝ่าย และค้นหาชื่อ–นามสกุลแบบบางส่วน ข้อมูลและไฟล์ส่งออกใช้การค้นหาเดียวกัน ผู้ใช้ทั่วไปยังค้นได้เฉพาะข้อมูลของตน แอดมินค้นได้ทุกคนในฐานบุคลากรของปีนั้น ไฟล์ XLSX/CSV เพิ่มลำดับ 1, 2, 3 ก่อนคอลัมน์รหัส และนำคอลัมน์ที่เลิกใช้ออกจากรายงานใหม่
